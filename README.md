# Hoardify

A full-stack outdoor advertising hoarding booking platform built with Next.js 16 App Router.

## Portals

- **Public Website** — Browse hoardings, explore by city, pricing, about, contact
- **Advertiser Portal** — Dashboard, bookings, payments, subscriptions, profile
- **Super Admin Portal** — Manage hoardings, locations, advertisers, bookings, payments, CMS, settings

## Tech Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- Framer Motion
- Lucide Icons
- Recharts
- React Hot Toast

## Getting Started

```bash
cd hoardify-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
